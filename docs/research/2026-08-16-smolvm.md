## 它是什么

smolvm 是用 Rust 编写的本地、轻量、可移植 microVM CLI，目标是默认隔离地运行软件。它提供两种生命周期：`machine run` 创建并在命令结束后清理的临时 VM，或 `machine create/start/exec/stop` 管理可持续保存软件包和文件系统状态的 VM。[项目 README](https://github.com/smol-machines/smolvm/blob/0d7da4a2192b693e0b5b09be59adda85c7db3017/README.md)

## 架构与数据路径

- 每个 workload 使用独立 guest kernel 和硬件虚拟化 VM；macOS 走 Hypervisor.framework，Linux 走 KVM，Windows x86_64 走 Windows Hypervisor Platform。libkrun 负责 VMM，libkrunfw 提供 guest kernel。[工作原理与平台](https://github.com/smol-machines/smolvm/blob/0d7da4a2192b693e0b5b09be59adda85c7db3017/README.md#how-it-works)
- 输入边界采用 OCI 镜像：可以从 Docker Hub/GHCR 等 registry 拉取，也可以直接使用 `docker save`/`podman save` 归档或 unpacked rootfs；不要求 Docker daemon。资源默认是 4 vCPU、8 GiB RAM，内存通过 virtio balloon 弹性分配。[镜像与资源](https://github.com/smol-machines/smolvm/blob/0d7da4a2192b693e0b5b09be59adda85c7db3017/README.md#how-it-works)
- `pack create` 把 rootfs、OCI 层和 storage 封装为 `.smolmachine`，再由平台相关的可执行 stub 或 `machine create --from` 重新启动；产物要求宿主 OS/架构匹配。[打包示例](https://github.com/smol-machines/smolvm/blob/0d7da4a2192b693e0b5b09be59adda85c7db3017/README.md#use-this-for)

## 安全模型

网络默认关闭；`--net` 才启用出站网络，`--allow-host` 和 `--allow-cidr` 可进一步收窄 egress，端口转发则会扩大暴露面。宿主目录挂载是显式授权，不能把密钥目录挂给不可信 workload。SSH agent forwarding 不复制私钥，但 guest 可以在转发存续期间请求签名，因此应只对可信 workload 开启。[网络与凭据](https://github.com/smol-machines/smolvm/blob/0d7da4a2192b693e0b5b09be59adda85c7db3017/AGENTS.md#networking) [安全边界](https://github.com/smol-machines/smolvm/blob/0d7da4a2192b693e0b5b09be59adda85c7db3017/README.md#security-model)

这不是完整的多租户控制平面：CLI/VMM 以宿主用户权限运行，宿主 OS、hypervisor、libkrun 和 smolvm 都属于信任计算基。`--secret-env`/`--secret-file` 是延迟解析、以明文注入 guest 进程环境的防御纵深机制，不能替代零知识密钥方案；guest root 仍可读取自己进程环境中的秘密。[安全模型与秘密说明](https://github.com/smol-machines/smolvm/blob/0d7da4a2192b693e0b5b09be59adda85c7db3017/AGENTS.md#secrets)

## 适用性判断

它适合在开发机、CI 或 Agent 执行器中运行不可信代码，同时保留 OCI 工作流和持久 VM 的便利；相较共享内核容器，隔离边界更强，相较完整 QEMU，启动和分发成本更低。不要把 README 的启动时间或“弹性资源”当成所有工作负载的 SLA：实际结果仍取决于宿主 hypervisor、架构、镜像和 I/O。GPU/CUDA 是额外的能力边界，CUDA remoting 仍共享宿主 GPU，不能当作硬件级多租户 GPU 隔离。[限制与平台说明](https://github.com/smol-machines/smolvm/blob/0d7da4a2192b693e0b5b09be59adda85c7db3017/README.md#known-limitations) [Agent 参考](https://github.com/smol-machines/smolvm/blob/0d7da4a2192b693e0b5b09be59adda85c7db3017/AGENTS.md)
